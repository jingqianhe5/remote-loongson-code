# 写作说明

- 所有技术描述以当前 RTL 实现为准，不引用过时 README。
- 文风采用竞赛技术报告风格，突出实现路径、接口定义和设计理由。
- CPU 可见的 LACC 主命令编码与 CPU—TPU 异步 FIFO 命令编码必须分开说明。
- 后续补充 RTL 仿真波形和上板测试结果。
- 1.1和1.2以当前顶层为准：系统为CPU、DMA、TPU三主设备和八个AXI目标窗口，M6当前仅预留。
- 时钟结构按`cpu_clk`、`sys_clk`、`tpu_clk`三个独立域描述；当前配置频率约为32.98 MHz、50 MHz和50 MHz。
- ISP算法和配置接口已经接入，但直接视频输入仍为后续集成点，正文不得描述为已经闭合的实时视频链路。
- 1.1与1.2的表号当前从表1-1连续到表1-3；与1.3合并排版时，需要统一调整后续表号。
- 3.3节以当前推理版TPU为准。`gradient_descent.sv`、损失函数和训练仿真属于早期参考版本遗留材料；当前AXI集成顶层将学习率与`2/N`置零，VPU只直通脉动阵列结果，UB训练端口仅保留接口兼容性，正文不得写成支持片上训练。
- TinyTPU只作为结构参考来源，当前实现参数以本仓库RTL为准：8×8阵列、16位Q8.8输入/权重、32位累加、2048×16位八银行UB。
- TPU章节采用作品介绍式竞赛报告语言，重点讲清设计动机、加速原理、数据流和系统协同；实现边界集中放在演进与验证部分，不在正文中反复使用“不能直接作为性能”等评审口吻。
