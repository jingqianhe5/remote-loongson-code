# 项目概览

## 基本信息

- 报告类型：集成电路设计竞赛技术报告
- 技术方向：异构 SoC 与计算机体系结构设计
- 项目名称：农芯种科 SoC
- 输出格式：中文 Markdown
- 当前阶段：TPU矩阵乘法章节写作

## 设计背景

系统以 LA500 为控制核心，并集成 TPU、DMA、ISP 和 DVI 等模块。为降低 CPU 配置 TPU、搬运少量控制数据和读取计算结果时的软件及总线开销，CPU 内部增加 LACC 自定义指令通路，使处理器能够直接下发 TPU 控制命令并读取状态和结果。

## 设计目标

在保留 LA500 原有流水线和 AXI 主接口的基础上，完成自定义指令译码、执行级握手、流水线阻塞、结果写回和 CPU—TPU 跨时钟通信，实现紧耦合的异构协同机制。

## 验证方法

通过 RTL 仿真检查指令译码、命令握手、流水线暂停、状态返回和结果读取，并通过上板软件测试验证 TPU 控制与推理流程。
