# 报告大纲

## 1.1 SoC整体架构

从图像处理与智能推理任务出发，说明 LA500、TPU、DMA、ISP、DVI、共享 SRAM 和板级外设之间的分工。按照输入、搬运、处理、推理和输出的数据流组织正文，说明 CPU 负责调度、TPU负责矩阵计算、DMA负责批量数据搬运，避免将本节写成模块清单。

### 1.1.1 系统组成与任务分工

说明系统的计算、存储、图像处理、数据搬运、视频输出和控制外设，给出三类AXI主设备的访问职责。

### 1.1.2 控制面与数据面

说明 CPU—TPU 的 LACC 命令/结果异步 FIFO 属于控制与结果通路，TPU程序、描述符和批量计算数据通过共享 SRAM 与 AXI 数据通路传输。

### 1.1.3 时钟与复位域

说明 `cpu_clk`、`sys_clk` 和 `tpu_clk` 三个时钟域，以及 CPU AXI CDC、TPU AXI CDC、命令FIFO、结果FIFO和单比特状态同步器的分工。

## 1.2 AXI互连与地址空间

### 1.2.1 三主八目标端口互连

说明 32 位地址、32 位数据的 3×8 AXI Crossbar，三个输入端分别连接 CPU系统侧接口、DMA和TPU，八个输出地址窗口连接存储器和外设。

### 1.2.2 地址译码与事务仲裁

说明地址窗口译码、不同目标端口并行访问、同一目标端口轮询仲裁、事务ID扩展和返回路由。

### 1.2.3 地址空间与接口适配

给出当前RTL地址映射，说明M6为预留窗口，DMA和ISP配置接口通过AXI-to-AXI-Lite适配器连接，并以总线数据通路与LACC专用通路的关系承接1.3节。

## 1.3 CPU内部基于龙芯的自定义指令集修改

本节说明 LA500 为支持 TPU 紧耦合控制所进行的 RTL 修改，论述顺序采用从软件指令到硬件执行、再到 TPU 反馈的输入—输出技术流。

### 1.3.1 指令扩展目的

说明仅依赖存储器映射寄存器控制 TPU 时的指令数量、总线事务和轮询开销，给出采用 LACC 专用通路的设计理由。

### 1.3.2 自定义指令编码

说明 32 位 LACC 指令的主操作码、command、imm、rk、rj 和 rd 字段；区分 CPU 可见的四类主命令与发送到 TPU 命令 FIFO 的四类有序命令。

### 1.3.3 CPU流水线修改

按照译码级、执行级和写回路径说明指令识别、操作数读取、控制信息传递、valid/ready 阻塞、结果前递及寄存器写回。

### 1.3.4 LACC控制核心

说明命令判定、状态字生成、64×16 位结果缓冲区、有效位、两种结果组织模式和错误码。

### 1.3.5 CPU—TPU协同流程

说明命令 FIFO、结果 FIFO和单比特状态同步器之间的分工，给出 CLEAR、数据准备、START、STATUS 和 READ 组成的完整任务时序。

### 1.3.6 软件调用与验证

说明通过内联汇编 `.word` 嵌入机器码的方法，以及 RTL 仿真与上板测试需要检查的信号和结果。

## 3.3 矩阵乘法原理与设计

本节以当前推理版RTL为依据，参考TinyTPU的统一缓冲区、脉动阵列和向量后处理分层方式，按照矩阵数据进入UB、阵列执行乘累加、结果定点化输出及CPU调度的顺序组织正文。训练版源码中出现的损失、梯度和参数更新模块只作为设计演进背景，不表述为当前SoC已经实现的能力。

### 3.3.1 基本结构

说明2048×16位八银行统一缓冲区、8×8 PE阵列、直通型VPU、指令译码和AXI取指/DMA控制器之间的连接，并给出Q8.8输入、Q16.16乘积、32位部分和及Q8.8饱和输出的数据流。

### 3.3.2 TPU专用指令集

说明32位TPU内部微指令的操作码与字段，覆盖NOP、LOAD、SET_WR、UB_READ、SWITCH、WAIT和END；将训练相关SET_GRAD_ADDR标记为兼容保留、当前推理程序不使用。

### 3.3.3 与CPU的通信

承接1.3节LACC自定义指令，说明CPU通过CLEAR、DMA_LOAD、START、STATUS和READ完成任务控制，TPU程序与批量矩阵数据经AXI读取，命令和结果经异步FIFO跨越CPU与TPU时钟域。

### 3.3.4 梯度计算取舍与现存问题

说明当前设计不计算梯度、不执行反向传播和片上权重更新，并分析定点范围、阵列填充排空、非8倍数矩阵、分块累加、权重切换与关键乘加路径等工程问题。

### 3.3.5 仿真验证

说明`tpu_dma_tb.sv`对DMA装载、指令缓存、计算与搬运重叠、8×8矩阵乘法、权重双缓冲、Q8.8小数精度和输出饱和的检查方法，以软件参考值逐项比较RTL结果。

## 3.4 DMA设计、AM移植与《超级马里奥》运行

按照从硬件到应用的竞赛报告技术链路组织：先说明DMA卸载CPU搬运的基本原理，再展开AXI读写引擎、描述符和反压机制，随后说明Crossbar集成、寄存器控制和视频帧搬运，最后引出AM运行时、FCEUX与Mario ROM。区分旧DVI的DMA路径与新版DVI默认CPU直写路径，并如实记录输入驱动尚未实现的边界。

## ISP与DMA总线寄存器说明

给出DMA与ISP的AXI物理地址、CPU非缓存别名、全部寄存器偏移、访问属性、复位值和位域功能，并说明DMA提交时序、ISP算法选择编码及当前顶层尚未接通的视频与AWB功能。

## TPU原理与SoC实现

按照从计算原理到系统软件的技术链路，说明神经网络矩阵计算、Q8.8定点格式、PE双缓冲、8×8脉动阵列、2048×16位统一缓冲区、直通VPU、TPU微指令、AXI取指和数据装载、LA500 LACC协同、算子任务映射及验证边界。训练相关源码只作为兼容接口说明，不计入当前前向推理能力。
